# Ejemplos de contrato

`specs/minimal.moana.json` y `specs/recolor.edit.json` corresponden a MOANA.md §§12–15. Se comprueba JSON bien formado en la inicialización; la validación Pydantic y la ejecución se incorporarán en MOA-002 y MOA-018. No son sprites profesionales ni una demostración del motor.

El documento base usa revision=0 y el batch cambia sólo la referencia de color de body_fill. La salida prevista conserva geometría y capas, e incrementa la revisión a 1. Los ejemplos artísticos y sus PNG se producirán en MOA-027 y MOA-034 con procedencia documentada.
