# Contratos entre módulos

Estado: **contratos previstos**, salvo `core` (con el lienzo RGBA), `schema`, `palette`, `geometry`, `layers`, `techniques` (dithering ordenado, contornos, clusters y sombreado por bandas), `render`, `export` PNG, `editing`, `project`, `animation` (timeline y evaluación de frames) y `api`/`cli` (implementados, ver abajo). Las firmas públicas objetivo están en [MOANA.md §13](../../MOANA.md); sus fórmulas, límites y formatos prevalecen sobre este resumen. No se añaden abstracciones base ni registros de plugins por anticipación.

## Entradas, salidas y efectos

| Módulo | Entrada y salida previstas | Responsabilidad y efectos permitidos |
| --- | --- | --- |
| `core` | Coordenadas/cajas/límites → valores tipados y errores | Contratos independientes de módulos superiores; reserva de buffers sólo tras presupuesto |
| `schema` | JSON o mapping → documento normalizado / errores con pointer | Tipos estrictos, defaults, discriminadores y schema; no dibuja ni abre paths contenidos en operaciones |
| `palette` | Colores/rampas referenciados por ID → tabla resuelta / remapeo explícito | Valida perfil y cardinalidad; no cuantiza silenciosamente |
| `geometry` | Parámetros enteros y límites → máscara binaria acotada | Rasterización, clipping y transformaciones; no conoce historial, CLI o disco |
| `layers` | Nodos ordenados, máscaras y buffers → composición RGBA | Orden, visibilidad y grupos; posee sus temporales y aplica opacidad una vez por grupo |
| `techniques` | Máscaras, rampas, patrón y semilla → operaciones/máscaras/colores derivados | Contornos, bandas y materiales editables; no elimina detalles automáticamente |
| `render` | Documento validado, frame y límites → resultado inmutable | Resuelve referencias/capacidades, estima coste y ejecuta plan; sin escritura de archivos |
| `editing` | Documento + batch tipado → documento nuevo o conflicto | Transacción completa, IDs estables y revisión; sin rasterización ni persistencia interna |
| `project` | Bytes/path autorizado + raíz de assets → documento, assets e historial verificados | I/O confinado, hashes e historial; migraciones explícitas a un destino nuevo con copia original preservada (ADR-031); guardado atómico con commit final del manifiesto |
| `animation` | Base + timeline/overrides → frames evaluados, duraciones, pivote y resultados | Evalúa cada frame contra la base con las reglas del editor, sin revisión; admite el presupuesto acumulado antes de renderizar; no escribe archivos |
| `export` | Resultado/frames + opciones + destino autorizado → manifiesto | Codificación y escritura atómica; no llama al editor ni cambia el documento |
| `quality` | Resultado, paleta y configuración → incidencias y métricas | Diagnóstico estable y no mutante; separa reglas duras de heurísticas artísticas |
| `api` / `cli` | Solicitud del llamador → resultado, informe o código de salida | Orquesta servicios, autoriza I/O de aplicación y traduce errores; no duplica algoritmos |

## `core` (implementado en MOANA-001)

API pública en `moana.core`, sin dependencias de otros módulos Moana, NumPy ni Pillow; los adaptadores del lienzo son submódulos aparte (abajo). Decisiones en [ADR-010](decisions/ADR-010-core-contracts.md).

| Tipo | Contrato |
| --- | --- |
| `Point(x, y)` | Inmutable; `x`/`y` son `int` reales (se rechazan `bool`, float, str y escalares NumPy) con `abs ≤ 1 048 576`. Se indexa como `array[y, x]`. |
| `Dimensions(width, height)` | Cada eje en 1–2048, área ≤ 4 194 304; `Dimensions.default()` es 128 × 128. `check_pixel(point)` lanza `OutOfBoundsError` fuera del lienzo, sin wraparound de índices negativos. |
| `Box(x0, y0, x1, y1)` | Semiabierta `[x0,x1) × [y0,y1)`, nunca vacía (`x0 < x1`, `y0 < y1`). `x0`/`y0` en `±1 048 576`; `x1`/`y1` hasta `1 048 577`. Una caja 1 × 1 contiene exactamente un píxel (`Box.from_point`, válido para todo píxel). Puede quedar fuera del lienzo. |
| `Box.intersection` / `Box.clip_to` | Devuelven la caja común o **`None`** si no queda ningún píxel (incluidas cajas que sólo se tocan en un borde). Nunca se construye una caja vacía o invertida para representar «nada». |
| `MAX_LAYERS`, `MAX_OPERATIONS`, `MAX_VERTICES`, `MAX_COLORS_STRICT`, `MAX_COLORS_RGBA` | Límites de cardinalidad del documento (§20), compartidos por `schema`, `palette` y `render` (ADR-011). |
| `GeometryLimits` / `DEFAULT_GEOMETRY_LIMITS` | Máximos geométricos del contrato §5 (eje, área, coordenada), separados de su aplicación (`check_dimensions`, `check_point`, `check_box`). Sólo pueden bajar; el documento no los define. Los presupuestos elevables de §20 son `RenderLimits`, que compone este tipo. |
| `RenderLimits` / `DEFAULT_RENDER_LIMITS` | Presupuestos por solicitud de §20 (bytes de buffers con temporales, visitas de píxel, píxeles de frames, operaciones, capas) y `geometry`. Se bajan libremente; elevar un presupuesto exige `host_override=True` del anfitrión; conteos y geometría nunca superan el contrato. ADR-012. |
| `Deadline` | Comprobación cooperativa entre unidades de trabajo (`checkpoint`), `BudgetExceeded` con recurso `time`; no influye en el resultado ni interrumpe código nativo. |
| `require_int` | Validación compartida de enteros con rango; `minimum > maximum` es error de programación (`ValueError`). |
| `combined_box(operator, boxes, dimensions)` | Caja de una combinación de máscaras a partir de las cajas de sus operandos (`None` = vacío), recortada: la primera en `subtract`, la parte común en `intersect` y la envolvente en el resto. Aritmética pura con el operador como `str`, que valida el llamador; la consumen `moana.geometry.combined_box` y el plan de coste (ADR-022). |
| `moana.core.ids` | Dueño único de los lenguajes léxicos: `ID_REGEX`/`ID_PATTERN` (`[a-z][a-z0-9_-]{0,63}`) y `RGBA_HEX_REGEX`/`RGBA_HEX_PATTERN` (`#RRGGBBAA`); `is_id`, `is_rgba_hex` y `check_id` aceptan sólo `str` exacto con `fullmatch`. `schema` publica estos patrones. ADR-014. |
| `MAX_RAMP_ENTRIES` | Total de miembros de rampa de una paleta (20 000); acota paletas construidas fuera del lector del esquema. |
| `MAX_GROUP_DEPTH` | Anidamiento máximo de grupos en el árbol de capas (16, §11); lo aplica `layers` y lo aplicará `schema` cuando admita grupos. |
| `MAX_MASKS`, `MAX_MASK_OPERANDS`, `MAX_MASK_DEPTH`, `MAX_REGIONS` | Máscaras (1024), operandos por combinación (64), cadena de referencias más larga (16) y regiones (1024) de §11; los aplican `schema` y `layers` (ADR-022). |
| `MAX_PATH_COMMANDS`, `MAX_PATH_SEGMENTS`, `MAX_PATH_CURVE_SEGMENTS`, `MAX_PATH_CELLS` | Paths ([ADR-023](decisions/ADR-023-aggdraw-paths.md)): 2–4096 comandos, 65 536 segmentos aplanados (incluido el cierre de cada subpath), 64 segmentos por curva y 2 097 152 celdas AGG por path; este último es un límite del motor (AGG descarta celdas en silencio a partir de 4 194 304) y no se eleva con `host_override`. |
| `moana.core.dither` | Constantes de sólo datos del dithering ordenado ([ADR-025](decisions/ADR-025-ordered-dithering.md)): `DITHER_SIZES` = (2, 4) y `PATTERN_INDEX_BYTES` = 8. Única definición; las usan `schema`, `techniques`, `geometry` y el plan de coste sin cargar NumPy. |
| `moana.core.shading` | Constantes de sólo datos del sombreado por bandas ([ADR-028](decisions/ADR-028-band-shading.md)): `LIGHT_DIRECTIONS` (ocho del plano en sentido horario desde `n`, y `front`), `FACINGS` (más `none`), `RAMP_ORDERS` (`monotonic`, `stylized`), `MAX_LIGHT_HEIGHT` = 3, `MAX_RAMP_STEP` = 4095 y `MAX_SHADE_BANDS` = 64. Única definición; las usan `schema` y `techniques` (el plan de coste no las lee). |
| `moana.core.materials` | Recetas versionadas de materiales ([ADR-030](decisions/ADR-030-material-presets.md)): `MaterialPreset(name, version, pattern, parts, channels, max_density, max_scale, description, provenance, license)` congelado; `MATERIAL_PRESETS` (vista de sólo lectura por `(name, version)`; una versión publicada nunca cambia), `preset(name, version)` (fila o `None`; tipos exactos), `MATERIAL_PRESET_NAMES`, `MATERIAL_PATTERNS`, `DENSITY_STEPS` = 64, `MAX_MATERIAL_SCALE` = 8, `MAX_MATERIAL_ORIGIN` = 2048 y `cell_span(box, scale, origin)` (caja de celdas por división entera hacia abajo). Datos puros: las leen `schema`, `techniques` y el plan de coste sin NumPy. |
| `moana.core.procedural.cell_choices(seed, operation_id, span, channel, n, *, deadline)` | Vectoriza `cell_choice` sobre una caja de celdas (≤ `MAX_GRID_CHOICES` = 256 opciones): `bytes` fila a fila, idénticos a la versión escalar (`cell-sha256-v1`), con un estado SHA-256 de prefijo copiado y plazo cada 16 filas ({A30}). |
| `moana.core.morphology`, `grown_box`, `MAX_MORPHOLOGY_RADIUS`, `MAX_CLUSTER_RUNS`, `MAX_CLUSTER_EXCEPTIONS` | Aritmética pura de la morfología ([ADR-027](decisions/ADR-027-outlines-clusters.md)): `morphology_bytes(caja, r)` = `2·área + 4·P + 4·área + 12·min(P, 8192) + 4096` con `P = (W + 2r + 1)·(H + 2r + 1)` (búferes de iteración de NumPy, `UFUNC_BUFFER_ITEMS`; `MORPHOLOGY_FIXED_BYTES`), `coordinates.grown_box(caja, r, dims)` (caja recortada, crecida `r` y recortada otra vez); radio máximo 16 (también `width` máximo de `outline`) 262 144 runs opacos por análisis de clusters (`BudgetExceeded` `cluster_runs`) y 64 excepciones por análisis (`too_many_exceptions`, un bit de `uint64` cada una). Única definición; las usan `geometry`, `techniques`, `schema` y el plan de coste sin cargar NumPy. |
| `MAX_MIGRATION_STEPS`, `MAX_PROJECT_MIGRATIONS` | Migraciones ([ADR-031](decisions/ADR-031-format-versions-migrations.md)): pasos de una cadena registrada hasta la versión actual (16; lo comprueba `MigrationRegistry` al construirse) y registros de migración de un proyecto (8; `Project`, `ProjectLimits.max_migrations`). |
| `moana.core.vector_path` | `parse_path(commands) -> FixedPath`: gramática M/L/Q/C/Z en punto fijo 1/256 (`PATH_UNITS`, `MAX_PATH_COORDINATE` = 268 435 456), sólo enteros exactos (sin `bool` ni float); primer comando M, sin subpaths vacíos, sólo M tras Z; cierre implícito de subpaths abiertos. Aplanado entero (Bernstein con redondeo a par, pasos mínimos con tolerancia 1/16 px, 1–64 por curva). `FixedPath` expone `bounds`, `reach`, `manhattan_length`, `cell_bound(box)` y `outline()`, sin dependencias externas: el plan de coste lo usa sin cargar AggDraw. `PathCommand` y `FixedPath` se revalidan al construirse (`segments` se deriva). Errores `ValidationError` con `field: commands`, índice y motivo. Comparte con el plan y el adaptador `PATH_BUFFER_MARGIN`, `path_buffer_box`, `path_raster_visits` y `path_raster_bytes`. |
| `errors.detail_sort_key` | Orden canónico de `ErrorDetail` (pointer con índices numéricos, código, mensaje), compartido por `schema` y `palette`. |

Errores (`moana.core.errors`): `MoanaError` (código `INTERNAL_ERROR`, salida 1) y subclases con `code` estable y `exit_code`: `ValidationError` (`VALIDATION_ERROR`, 2), `OutOfBoundsError` (`OUT_OF_BOUNDS`, 2, subclase de validación), `ReferenceError` (`REFERENCE_ERROR`, 2; distinto del builtin homónimo, importar como `errors.ReferenceError`), `UnsupportedVersion` (2), `UnsupportedOperation` (2), `BudgetExceeded` (3), `EditConflict` (4), `ExportError` (5) y `ReadError` (`READ_ERROR`, 5; ADR-020). Atributos de sólo lectura `message`, `json_pointer` (opcional, RFC 6901) y `context`. `context` es inmutable y sólo admite escalares o tuplas: nombres de campo, motivos, tipos y límites numéricos; nunca strings de entrada no confiable ni rutas. Los errores son picklables.

Lienzo (MOANA-004, [ADR-013](decisions/ADR-013-canvas-buffer.md)): adaptadores explícitos que `moana.core` no importa, para que `schema` y el plan de coste no carguen bibliotecas gráficas.

| Tipo | Contrato |
| --- | --- |
| `moana.core.canvas.Canvas` | Propietario exclusivo de un buffer `uint8` C-contiguo `(height, width, 4)`, RGBA recto, alfa cero normalizado a `(0,0,0,0)`. `blank(dimensions, *, limits)` y `from_array(array, *, limits)` (límites obligatorios) validan tipo, dtype, forma y presupuesto antes de copiar o reservar. `get_pixel`/`set_pixel` con `Point` lanzan `OutOfBoundsError` fuera del lienzo, sin wraparound. `to_array()` (copia escribible), `to_bytes()`, `copy()`, `visual_digest()` (§14). Mutable y sin hash; igualdad por tamaño y bytes; construcción directa cerrada y `copy.copy`/`deepcopy` copian el buffer. No llega a la fachada: `RenderResult` guarda bytes inmutables (ADR-013). |
| `moana.core.canvas.check_canvas_budget` | Geometría del anfitrión y `4 × A` bytes contra `RenderLimits`; `BudgetExceeded` con los mismos recursos que `plan_budget`. |
| `moana.core.pillow_adapter` | `canvas_to_pillow(canvas)` crea una imagen `RGBA` nueva; `canvas_from_pillow(image, *, limits)` acepta sólo `RGBA` de un frame ya abierto, sin conversión implícita, y copia; una imagen cerrada o truncada da `ValidationError` (`unreadable_image`). |
| `moana.core.digest.visual_digest(width, height, rgba)` | Digest visual de §14 (`sha256:` sobre ancho y alto `uint32` big-endian + RGBA), sólo biblioteca estándar; única implementación, usada por `Canvas` y `RenderResult` (ADR-018). |
| `moana.core.procedural` | `cell_unit`/`cell_choice` y `RNG_VERSION`: aleatoriedad por celda de §14, sin estado (ADR-018). |

Integración con `schema` (MOANA-002): los errores de `core` no derivan de `ValueError`, así que Pydantic no los convierte en errores de campo. `schema` valida los enteros primitivos con las constantes de `core` (`Field(ge=..., le=...)`) y expone `Point`/`Box`/`Dimensions` como propiedades de los modelos. Un error con varios problemas lleva `details: tuple[ErrorDetail, ...]` (`code`, `json_pointer`, `message`, `context`), añadido de forma compatible por ADR-011.

## `render` — orquestador (MOANA-010)

`moana.render.render(document, *, frame_id=None, limits=None, deadline=None) -> RenderResult` ejecuta validación (revalida el árbol canónico) → frame (sólo `None`: `render` dibuja la base; un frame del documento es `ReferenceError` `frame_not_evaluated` y otro ID `unknown_frame`, con `field: frame_id`; los frames los evalúa `animation`, ADR-032) → rasterizador registrado (`RENDERABLE_OPERATION_TYPES`, incluidos `path` y `dither`; si no `UnsupportedOperation`) → backend de paths disponible y ensayado (si no `UnsupportedOperation` en `…/backend`, antes del presupuesto; ADR-023) → paleta resuelta → `plan_budget` → `LayerTree` de máscaras diferidas (las capas con `mask_id` reciben su expresión de máscara, un nodo por máscara del documento, con hojas diferidas; ADR-022; cada `dither` son dos fills diferidos, A y B, que evalúan su `mask_id` con `moana.layers.evaluate_mask` y conservan su parte con `moana.techniques.dither_mask`; ADR-025; cada `outline` es un fill diferido sobre `outline_box` que evalúa su `mask_id` y conserva `moana.techniques.outline_mask`; [ADR-027](decisions/ADR-027-outlines-clusters.md); cada `shade` es un fill diferido por banda, en orden, sobre la caja de la máscara de la banda y con el color `ramp[band_index(...)]`, que evalúa su máscara y le resta con `moana.techniques.last_wins` las máscaras de las bandas posteriores que la tocan (`shade_later`); con `ramp_order: "monotonic"` los hallazgos de `Palette.ramp_warnings` de su rampa son advertencias en `…/ramp`, y `stylized` omite los de luminancia no creciente; [ADR-028](decisions/ADR-028-band-shading.md); cada `material` es un fill diferido por banda y por paso de su receta, sobre la caja de la banda, que conserva la parte visible de la banda (regla de `shade`) intersecada con `moana.techniques.texture_mask` (semilla del documento, clave = ID de la operación) y la pinta con `ramp[clamp(índice de la banda + paso)]`; cada `selective_outline` es un fill base con `color` sobre la caja del contorno (anillo de `outline_mask` menos los tramos que lo tocan) y un fill por tramo con `ramp[band_index(...)]` sobre la intersección de la caja del tramo con la del contorno; las mismas advertencias de rampa; [ADR-030](decisions/ADR-030-material-presets.md)) → `compose`. No escribe ni lee disco, no modifica el documento y no usa caché, concurrencia, reloj ni `hash()`. Decisiones en [ADR-018](decisions/ADR-018-render-pipeline.md).

| Elemento | Contrato |
| --- | --- |
| `RenderResult` | Congelado: `width`, `height`, `rgba` (`bytes` filas de arriba abajo), `digest` (§14, recalculado al construir), `warnings` (`RenderWarning(code, message, json_pointer)`; `empty_bounds` por operación cuya caja recortada está vacía), `renderer_version` y `provenance`. `pixel(x, y)` lanza `OutOfBoundsError` fuera. Sin objetos NumPy. |
| `Provenance` | Manifiesto de reproducción: ID, revisión y `snapshot_digest` del documento, schema, semilla, perfil, frame, `renderer_version` (`render-v1`), `renderer_backend` (`integer`), `vector_backend` y `vector_backend_versions`, claves aditivas presentes en todos los renders (`aggdraw-v1` y `aggdraw==…`/`pillow==…` con paths; `null` y `[]` sin ellos; ADR-023), `estimator_version`, `rng_version`, `moana_version`; `to_mapping()` con claves ordenadas. Sin rutas, tiempos, lock ni plataforma. |
| `moana.render.budget.mask_box(operation, dimensions)` | Caja de almacenamiento de la máscara recortada (la misma que devuelve `geometry`) de una operación o de una hoja de máscara, usada por el plan y por las máscaras diferidas. |
| `moana.render.budget.mask_estimates(document)` | `MaskEstimate(box, pixel_visits, buffer_bytes)` de cada máscara (un ciclo o referencia rota de un documento sin validar es `ReferenceError`): caja del resultado, trabajo expandido y pico de evaluación (`budget-v8`, ADR-022, ADR-023, ADR-025, ADR-027, ADR-028 y ADR-030). |
| `moana.render.render_with_regions(document, region_ids, *, limits, deadline, extra_visits, extra_bytes)` | Render y mapping perezoso región → `Mask` (cada lectura reevalúa la máscara como una máscara de capa, con el `deadline`; sin caché). Valida una vez, resuelve las regiones antes de rasterizar (`unknown_region`) y admite toda la solicitud contra un solo `RenderLimits`: visitas = render + Σ (estimación de la máscara + área de su caja) + `extra_visits`; bytes = `max(pico del render, 4·área + extra_bytes + mayor pico de máscara de región)` (`BudgetExceeded` con cada recurso en `details`). La usa `api.analyze_clusters` ([ADR-027](decisions/ADR-027-outlines-clusters.md)). |
| `moana.render.plan_frame(document, *, limits, deadline, frame_index)` / `admit_sequence(estimates, *, limits)` / `render_admitted(document, *, frame_id, estimate, limits, deadline)` / `render_sequence(frames, *, limits, deadline)` | Admisión acumulada sobre `CostEstimate` sin retener documentos ([ADR-032](decisions/ADR-032-animation-timeline.md)). `plan_frame` comprueba backend y operaciones y aplica `plan_budget` a un documento de frame (un exceso añade `frame_index`). `admit_sequence` admite 1–256 estimaciones contra un solo `RenderLimits` y devuelve `SequenceBudget`: visitas = Σ; píxeles de frame = Σ áreas; bytes = mayor pico de trabajo de un frame + Σ (4·área + `RESULT_OVERHEAD_BYTES` = 2048) de los resultados retenidos (`BudgetExceeded` con `frames` en cada detalle). `render_admitted` revalida un documento, exige que su estimación sea la admitida (`ValueError` si no) y lo renderiza con `frame_id` en la procedencia. `render_sequence` encadena los tres pasos sobre pares `(frame_id, Document)` (1–256, longitud comprobada antes de recorrerlos, IDs únicos; si no, `TypeError`/`ValueError`) sin guardar copias revalidadas. `ESTIMATOR_VERSION` no cambia. |
| `moana.render.budget.outline_box(box, width, side, dims)` / `outline_cost(mask, width, side, dims)` | Caja declarada (crecida `width` para `outer`, la de la máscara para `inner`) y `(visitas, bytes)` de un `outline` sobre la estimación de su máscara (`budget-v6`, [ADR-027](decisions/ADR-027-outlines-clusters.md)). |
| `moana.render.budget.shade_later(boxes, index)` / `shade_cost(bands)` | Índices de las bandas posteriores cuya caja toca la de la banda `index` (las únicas que el render pliega) y `(visitas, bytes)` de un `shade` sobre las estimaciones de las máscaras de sus bandas (`budget-v7`, [ADR-028](decisions/ADR-028-band-shading.md)). |
| `moana.render.budget.material_cost(bands, recipe, scale, origin)` / `selective_outline_cost(mask, width, side, segments, dims)` | `(visitas, bytes)` de un `material` (por banda y paso: coste de banda de `shade` + `C·(64·k + 2) + 3·área` visitas; pico `max(banda, 2·área + 5·C + filas_celda·ancho + 8·(ancho + alto) + 16 384)`) y de un `selective_outline` (anillo de `outline_cost`, fill base que pliega los tramos que lo tocan y un fill por tramo) (`budget-v8`, [ADR-030](decisions/ADR-030-material-presets.md)). |
| `moana.render.budget.dither_cost(mask, size)` / `fill_count(document)` | Visitas y bytes de un `dither` sobre la estimación de su máscara, y fills rasterizados del documento (2 por `dither`, 1 por banda de `shade`, bandas × pasos por `material`, 1 + tramos por `selective_outline`), que es lo que compara el recurso `operations` de `plan_budget` ([ADR-025](decisions/ADR-025-ordered-dithering.md)). |

## `render` — plan de coste (MOANA-003, `budget-v2` en MOANA-010, `budget-v3` en MOANA-013, `budget-v4` en MOANA-007, `budget-v5` en MOANA-016, `budget-v6` en MOANA-014, `budget-v7` en MOANA-015, `budget-v8` en MOANA-017)

`moana.render.estimate_cost(document, *, frames)` calcula con aritmética entera, sin reservar ni recorrer píxeles, las visitas, bytes, píxeles de frames y conteos según las fórmulas de [ADR-012](decisions/ADR-012-request-budgets.md), con las visitas por operación de `budget-v2` ([ADR-018](decisions/ADR-018-render-pipeline.md): rasterizado más una pasada de pintado sobre la caja de la máscara) y el coste de las máscaras de capa de `budget-v3` ([ADR-022](decisions/ADR-022-masks-regions.md): expresión expandida sin memo, suelo de 1 visita por nodo evaluado (`MASK_NODE_VISITS`; un nodo de caja vacía cuesta sólo el suelo), `2×` caja por combinación no vacía más su coste y un plegado por operando, caja del resultado para copiar sus bits y `A` para limpiar fuera de la máscara; caja combinada con `moana.core.combined_box`; bytes = pico de evaluación + copia del resultado; sin máscaras coincide con `budget-v2`) y el coste de los paths de `budget-v4` ([ADR-023](decisions/ADR-023-aggdraw-paths.md): visitas `S + celdas + 3·área(B')` y bytes `área(B) + 2·área(B') + 24·celdas + 256·comandos + PATH_BACKEND_FIXED_BYTES` (128 KiB de heap nativo de AGG, invisible para `tracemalloc`), fórmulas de `moana.core.vector_path` (`path_raster_visits`/`path_raster_bytes`), con `B'` la caja recortada más 1 px de margen y la cota de celdas `min(2L + 3S, 3S·(W'+H'+1))`; sin paths coincide con `budget-v3`; un path que supera `MAX_PATH_CELLS` da el detalle `path_cells`, que `inspect_document` informa) y el coste del dithering de `budget-v5` ([ADR-025](decisions/ADR-025-ordered-dithering.md): `2·(visitas(M) + 4·área(Bm))` visitas y `bytes(M) + área(Bm) + 8·(ancho+alto)(Bm) + N·ancho(Bm) + 4096` bytes, con `M` la estimación de su máscara; el recurso `operations` compara fills rasterizados (`CostEstimate.fills`, 2 por `dither`; su `estimated` es `fills`) mientras `CostEstimate.operations` cuenta operaciones del documento, y `origin` se compara con la coordenada máxima; sin `dither` coincide con `budget-v4`) y el coste de los contornos de `budget-v6` ([ADR-027](decisions/ADR-027-outlines-clusters.md): con `X` la caja de trabajo (`Bm` crecida `w` y recortada para `outer`, `Bm` para `inner`) y `P = (ancho(X) + 2w + 1)·(alto(X) + 2w + 1)`, `visitas(M) + 16·P` visitas y `bytes(M) + área(Bm) + morphology_bytes(X, w) + 2·área(X)` bytes; un fill; sin `outline` coincide con `budget-v5`) y el coste del sombreado de `budget-v7` ([ADR-028](decisions/ADR-028-band-shading.md): por banda `i` con estimación `Mi` y caja `Bi`, y las bandas posteriores `j` cuya caja la toca, `visitas(Mi) + 4·área(Bi) + Σ (visitas(Mj) + área(Bi))` visitas y `área(Bi) + max(bytes(Mi), bytes(Mj)…) + 8192 (+ 24 576 si pliega alguna)` bytes; una banda vacía no cuesta nada; la operación suma visitas, su pico es el de la banda más cara y cuenta un fill por banda; sin `shade` coincide con `budget-v6`) y el coste de materiales y contorno selectivo de `budget-v8` ([ADR-030](decisions/ADR-030-material-presets.md): `material_cost` y `selective_outline_cost`; `operations` cuenta bandas × pasos y `1 + tramos`; el `origin` de un `material` se compara con la coordenada máxima; sin ellos coincide con `budget-v7`). El plan no importa AggDraw, NumPy ni `techniques`. `plan_budget(document, limits, *, frames, deadline)` lanza `BudgetExceeded` antes de cualquier buffer, con un detalle por recurso (`resource`, `limit`, `estimated`); una solicitud en el límite se admite. `frames` (≤256) cuenta renders idénticos; una animación suma un plan por frame evaluado. `plan_budget` es la única puerta para los límites del anfitrión: el orquestador (MOANA-010) sólo crea lienzos tras `plan_budget` y les pasa los límites de la solicitud; el lienzo repite su parte (`4A`, geometría) con el mismo `BudgetExceeded` como defensa en profundidad (ADR-013). Rasterizadores y compositor trabajan por filas o tiles dentro de estas cotas, con prueba `tracemalloc`, o actualizan el estimador.

## `layers` (implementado en MOANA-009; máscaras en MOANA-013)

API pública en `moana.layers`; depende de `core`, `palette` y `geometry` y usa NumPy internamente. `import moana.layers` no carga Pillow ni Pydantic. Decisiones en [ADR-017](decisions/ADR-017-layers-composition.md).

| --- | --- |

La tabla de imports permitidos de MOANA.md §3 impide dependencias ascendentes. Si dos módulos necesitan la misma representación, se extrae un contrato mínimo a `core` cuando el caso real lo requiera; no se resuelve un ciclo con imports tardíos o un contenedor global.

## Cruces que requieren validación

1. **Bytes → modelo:** limitar bytes/profundidad, rechazar claves duplicadas y tipos inesperados. Validar estructura antes de ejecutar código nativo.
2. **Modelo → plan:** comprobar unicidad de IDs, referencias, capacidades implementadas y aciclicidad. Una operación reconocida pero no disponible falla explícitamente.
3. **Plan → buffers:** estimar memoria total, temporales y trabajo. El clipping no elimina el coste previo de segmentos largos ni autoriza reservas enormes.
4. **Buffers → resultado:** fijar forma/dtype, normalizar transparencia y eliminar aliases mutables. El consumidor no puede alterar el resultado de una llamada anterior.
5. **Resultado → archivo:** verificar opciones representables, presupuesto del export y política de sobrescritura antes del commit del archivo.

Los errores de librerías se traducen en la frontera que conoce su significado, conservando la causa para diagnóstico interno. Un `BudgetExceeded` no se presenta como entrada válida con imagen parcial. Los resultados de fallo no reutilizan buffers parcialmente escritos como si fueran completos.

## Edición, referencias y dependencias visuales

La identidad de una operación no depende de su posición en un array. `set_color` cambia una referencia; modificar el valor de un color de paleta afecta a todos sus consumidores. Borrar un nodo referenciado se rechaza. Una modificación puede invalidar una sombra o contorno dependiente: el manifiesto debe distinguir el objetivo solicitado de los consumidores afectados.

Las máscaras forman un DAG independiente de los píxeles de una capa. No se permite definir una máscara mediante el render de la propia capa. Los grupos componen hijos en un buffer aislado antes de aplicar su opacidad. Esas decisiones impiden dependencias circulares y hacen que una región siga siendo identificable aunque cambie su apariencia.

Los batches se validan completos antes de producir una revisión. Historial, revisión numérica e identidad de snapshot deben seguir el contrato de MOANA.md §15; un implementador no debe añadir reglas diferentes de conflicto dentro del CLI. El formato persistente conserva esa identidad y la procedencia de migraciones.

## API, formatos y extensiones

La fachada (`moana.api`, MOANA-012) devuelve tipos documentados y estables. Objetos de Pillow, arrays escribibles y handlers de archivos abiertos quedan internos. Aceptar `Path` en una API de aplicación no autoriza incluir rutas arbitrarias en instrucciones JSON. La configuración de límites viene del anfitrión, no de un documento no confiable.

Cada operación nueva añade modelo, capability, resolución, estimación de coste, rasterizador, fixtures y documentación. El schema MVP implementa el vocabulario soportado por su issue; mencionar una futura técnica en la especificación no implica que sus parámetros o backend ya se acepten. Las ampliaciones se versionan junto con sus modelos, y se rechazan versiones no soportadas.

Exportadores adicionales declaran capacidad real del codec. GIF necesita política de paleta/alfa/duración; PNG RGBA conserva el maestro. El manifiesto del atlas permite reconstruir frames. El proyecto editable conserva documento y assets verificados; las imágenes de preview son derivadas.

| Frontera | Evidencia mínima |
